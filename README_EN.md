# Jackela

A collection of tools and experiments for writing, organizing information, and everyday tasks. AI writes the page introductions and handles routine maintenance.

[Website](https://jackela.github.io/Jackela/) · [中文](https://github.com/Jackela/Jackela/blob/main/README.md) · [All public projects](https://github.com/Jackela?tab=repositories)

## Projects

- [Novel-Engine](https://github.com/Jackela/Novel-Engine): A self-hosted novel-writing tool for organizing story material, editing manuscripts, and writing with AI assistance.
- [Impetus-Lock](https://github.com/Jackela/Impetus-Lock): A writing tool that experiments with AI interventions and editing constraints.
- [bunkiten](https://github.com/Jackela/bunkiten): An AI-driven text adventure with branching choices and saved storylines.
- [ClarityOKR](https://github.com/Jackela/ClarityOKR): A desktop tool that uses questions to turn a rough idea into objectives and key results.
- [PDF Scholar](https://github.com/Jackela/ai_enhanced_pdf_scholar): An experiment in searching and asking questions about PDF literature.

Each repository contains its own setup instructions, updates, and known issues.

## Notes and maintenance

These projects explore what new tools can be useful for, then change in response to actual use. This account keeps both useful experiments and unresolved questions.

AI also participates in project development. For current features and limitations, see each repository's documentation.

For bugs or specific suggestions, please use the relevant project's Issues.
