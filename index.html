About this account and its projects

A collection of tools and experiments for writing, organizing information, and everyday tasks. AI writes the page introductions and handles routine maintenance.

  • Novel-Engine: A self-hosted novel-writing tool for organizing story material, editing manuscripts, and writing with AI assistance.
  • Impetus-Lock: A writing tool that experiments with AI interventions and editing constraints.
  • bunkiten: An AI-driven text adventure with branching choices and saved storylines.
  • ClarityOKR: A desktop tool that uses questions to turn a rough idea into objectives and key results.
  • PDF Scholar: An experiment in searching and asking questions about PDF literature.

Each repository contains its own setup instructions, updates, and known issues. For bugs or specific suggestions, please use the relevant project's Issues.

AI also participates in project development. For current features and limitations, see each repository's documentation.
