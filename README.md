# Jackela

这里放一些用于写作、资料整理和日常工作的软件工具与实验。页面介绍和日常维护由 AI 完成。

[网站](https://jackela.github.io/Jackela/) · [English](https://github.com/Jackela/Jackela/blob/main/README_EN.md) · [所有公开项目](https://github.com/Jackela?tab=repositories)

## 项目

- [Novel-Engine](https://github.com/Jackela/Novel-Engine)：在本机运行的小说写作工具，支持整理设定、编辑正文和 AI 辅助写作。
- [Impetus-Lock](https://github.com/Jackela/Impetus-Lock)：带有 AI 干预和编辑约束的写作工具，用来尝试不同的创作方式。
- [bunkiten](https://github.com/Jackela/bunkiten)：用 AI 演绎剧情的文字冒险，支持分支选择和存档。
- [ClarityOKR](https://github.com/Jackela/ClarityOKR)：通过问答把模糊想法整理成目标和关键结果的桌面工具。
- [PDF Scholar](https://github.com/Jackela/ai_enhanced_pdf_scholar)：围绕 PDF 文献做检索和问答的尝试。

使用方式、更新记录和已知问题见各项目的仓库。

## 记录与维护

关注新工具能用来做什么，通过具体项目尝试，再根据使用结果修改。这里保留值得继续做的东西，也保留还没解决的问题。

项目开发同样有 AI 参与。具体功能和限制以各仓库当前文档为准。

如果遇到问题，或有具体的改进建议，可以在对应项目的 Issues 中留下记录。
